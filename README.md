# ABC QUEST — Android גרסה 7.5

גרסת בדיקה מעודכנת עם כלכלת גביעים וקרדיטים חדשה ולוגו משחק עם דמויות.

## איך מפיקים את APK 7.5

1. הורד מהשיחה את הקובץ `ABC_QUEST_Android_v75_להעלאה_GitHub.zip`.
2. בדף [ABC-QUEST](https://github.com/aviadlevi-sketch/ABC-QUEST) בחר **Add file → Upload files**.
3. העלה את ה־ZIP **כמות שהוא**, בלי לחלץ, ולחץ **Commit changes** לענף main.
4. היכנס ל־[GitHub Actions](../../actions/workflows/build-android-apk.yml) וחפש הרצה ירוקה בשם **Build ABC QUEST Android APK**.
5. מתוך **Artifacts**, הורד `ABC_QUEST_v7_5_TEST_APK`, חלץ אותו והתקן את `app-debug.apk`.

חשוב: הגרסה החדשה בנויה על אותו מזהה אפליקציית TEST ומפתח חתימה כמו גרסה 7.4. התקן **מעל גרסה 7.4**, בלי להסיר אותה, כדי לשמור את ההתקדמות המקומית.

## איזון הגרסה

- משחק = 8 שאלות.
- ארבעה ניצחונות ראשונים ביום בכל עולם: 220 גביעים ו־50 קרדיטים לניצחון.
- ניצחונות נוספים בעולם באותו יום: 110 גביעים ו־25 קרדיטים.
- משחקי כל העולמות: 110/25 לשני ניצחונות ראשונים ביום, ואחריהם 55/12.
- לימוד אות חדשה: 90 גביעים ו־20 קרדיטים (פעם אחת לאות).
- 24 דרגות התהילה: 0 עד 60,000 גביעים. גביעים אינם נצרכים ברכישה.
- דמויות: ארבע בכל עולם, הראשונה חינם; האחרות דורשות עמידה במשימות, סף גביעים ורכישה בקרדיטים.
- סקינים: דרישות תרגול, ימי משחק, סף גביעים ומחיר קרדיטים מוצגים ליד הפריטים.
