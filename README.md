# ABC QUEST — Android 7.1

משחק אותיות באנגלית לילדים דוברי עברית.

## הורדת APK מעודכן

1. פתחו את **Actions → Build ABC QUEST Android APK**.
2. בחרו את הרצת ה-build האחרונה המסומנת בירוק (החל מגרסה 7.1).
3. תחת **Artifacts**, הורידו `ABC_QUEST_v7_1_APK`.
4. חלצו את ZIP. בתוכו נמצא הקובץ `app-debug.apk`.
5. התקינו אותו בטלפון Android.

**לבדיקה:** במעבר מגרסה 7.0 לגרסה 7.1 ייתכן שיהיה צורך להסיר את הגרסה הישנה, משום שבניות Debug של GitHub Actions אינן חולקות בהכרח אותה חתימת APK. הסרה מוחקת נתוני התקדמות מקומיים. אם קיימת התקדמות שחשוב לשמור, גבו אותה תחילה דרך מסך ההתקדמות באפליקציה. אם המכשיר מציג `App not installed` / `signature mismatch`, הסירו את הגרסה הישנה ורק אז התקינו את החדשה.

### תיקונים ב־7.1

- גלילת מגע במסכי הבית, הדמויות, הלמידה והמשחקים באמצעות אזור גלילה אנכי בתוך WebView.
- Immersive fullscreen: שורת הסטטוס ופס הניווט מוסתרים; ניתן לחשוף אותם לזמן קצר במחווה מקצה המסך. ההתנהגות עשויה להשתנות לפי גרסת Android והגדרות המכשיר.
- אפשרות לארוז קובצי קול מוקלטים ומורשים, עם עדיפות להם על הקריינות המסונתזת.

### הקלטות קול אנושיות

אפשר להוסיף למאגר תיקייה `android-audio` עם המבנה הבא:

```
android-audio/
  names/
    A.mp3 ... Z.mp3
  phonemes/
    A.mp3 ... Z.mp3
  words/
    apple.mp3
    ball.mp3
    cat.mp3
    ... 
```

בבנייה הבאה GitHub Actions יעתיק אותם ל־`app/src/main/assets/audio`, ייצור אוטומטית `audio/manifest.js` וישלב אותם ב־APK. האפליקציה תשתמש בקובץ שמע מקומי כאשר הוא קיים ותחזור לשמע הקודם כאשר אינו קיים. לכן אפשר להתחיל עם כמה הקלטות ולשפר בהדרגה. אין צורך באינטרנט להשמעת קבצים שכלולים ב־APK.

לתנועות ולעיצורים נדרשות הקלטות **פונטיות** נכונות, לא הקראה של שמות האותיות. לדוגמה, הצליל `/b/` צריך להיות קצר ובלי להוסיף `uh`. כדאי לבחור קריינית אחת בהגייה אמריקאית, עוצמה עקבית וקובצי MP3 מונו באיכות 44.1/48kHz, ולוודא זכות שימוש והפצה בקבצים. סך יעד ההקלטות: 26 שמות אותיות + 26 צלילי אותיות + 156 מילים = 208 הקלטות.

**חשוב:** נכון לעכשיו *לא* הועלו הקלטות אנושיות למאגר; הגרסה המעודכנת רק מוכנה לקלוט אותן. הקול הנוכחי עדיין עלול להישמע סינתטי.

## בנייה

קובץ ה־ZIP `ABC_QUEST_Android_v7_פרויקט_לבניית_APK.zip` הוא מקור הגרסה הוותיקה. תהליך הבנייה מחלץ אותו ומחיל תיקונים מ־`android-patches/`, לרבות קוד Android החדש וההתאמות לגלילה ולשמע.

כל שינוי בענף `main` מפעיל את GitHub Actions. הבנייה משתמשת ב־Java 17, Android SDK 35 ו־Gradle 8.9. APK מיועד לבדיקות מקומיות, לא ל־Google Play.

**אבטחה ופרטיות:** המאגר כרגע ציבורי. אל תעלו אליו הקלטות ילדים, מידע אישי, קובצי נתוני משתמשים, סיסמאות או מפתחות חתימה.
