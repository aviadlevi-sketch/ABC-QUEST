# ABC QUEST — גרסה 7.4 ל־Android

משחק לימוד אותיות באנגלית עם 4 עולמות, 16 דמויות ו־64 סקינים.

## הורדת גרסה 7.4 לטלפון

**[הורדת APK גרסה 7.4 — הרצה מאומתת](https://github.com/aviadlevi-sketch/ABC-QUEST/actions/runs/38879787152/artifacts/12037265623)**

1. פתח את הקישור בחשבון GitHub שלך.
2. הורד את קובץ `ABC_QUEST_v7_4_TEST_APK` (זהו ZIP של GitHub).
3. חלץ את הקובץ `app-debug.apk` והעבר אותו לטלפון Android.
4. התקן אותו מעל **ABC QUEST · TEST** של גרסה 7.3. מזהה האפליקציה ומפתח חתימת הבדיקות לא השתנו, ולכן אין צורך להסיר את האפליקציה; ההתקדמות המקומית אמורה להישמר.

## מה תוקן?

- בארבעת הניצחונות המזכים הראשונים ביום **בכל עולם**: 6 גביעים ו־12 קרדיטים למשחק.
- מניצחון מספר 5 באותו עולם באותו יום: 3 גביעים ו־6 קרדיטים — **אין הפסקת ניקוד**.
- בתרגול ״כל העולמות״: שני ניצחונות ראשונים מזכים ב־3 גביעים ו־6 קרדיטים; אחריהם 2 גביעים ו־3 קרדיטים לכל ניצחון.
- אות חדשה מזכה פעם אחת ב־4 גביעים וב־6 קרדיטים.
- דרגות התהילה חזרו להיות מבוססות על גביעים. 24 הדרגות נפרסות מ־0 ועד 520 גביעים, בקצב שנועד למסע של כעשרה ימי תרגול עבור כ־8–12 ניצחונות ביום. זהו יעד איזון, לא חסימה קשיחה.
- המסלול של כל עולם: הדמות השלישית דורשת 5 ניצחונות בשני ימי תרגול, והרביעית 10 ניצחונות בשלושה ימים. עולם שכבר נפתח בגרסה קודמת אינו ננעל מחדש.
- תמונות כל 64 הדמויות והסקינים נארזות כקובצי JPEG, למניעת שיבושי צבע ותצוגה ב־Android WebView.
- תוקן גודל כרטיס הדמות במסך הבית במכשירים צרים.

## בניות חוזרות

תהליך [Build ABC QUEST Android APK](../../actions/workflows/build-android-apk.yml) משתמש בארכיון גרסה 7.3 שכבר נמצא במאגר ומחיל עליו את סקריפט `android-patches/upgrade_v74.py`; אין צורך להעלות ZIP נוסף.

קובץ APK זה הוא **גרסת TEST חתומה בחתימת בדיקה בלבד**, ולא מיועד ל־Google Play.

**פרטיות:** המאגר ציבורי. אין להעלות אליו מידע אישי של ילדים, נתוני התקדמות, הקלטות פרטיות או מפתחות חתימה אמיתיים.
