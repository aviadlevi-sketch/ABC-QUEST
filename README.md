# ABC QUEST — גרסת Android 7.5

משחק ללימוד אותיות באנגלית לילדים. ארבעה עולמות, 16 דמויות, 64 סקינים, סולם תהילה בן 24 דרגות ולוגו הרפתקאות עם דמות ואותיות.

## הפקת APK דרך GitHub

1. הורד מצ'אט ChatGPT את `ABC_QUEST_Android_v75_להעלאה_GitHub.zip`.
2. לחץ כאן: [ABC QUEST Repository](https://github.com/aviadlevi-sketch/ABC-QUEST).
3. בחר **Add file → Upload files** והעלה את **קובץ ה־ZIP עצמו, ללא חילוץ**.
4. לחץ **Commit changes** לענף `main`.
5. הבנייה תתחיל אוטומטית תחת [Actions](../../actions/workflows/build-android-apk.yml).
6. בחר את ההרצה הירוקה האחרונה, הורד **Artifacts → ABC_QUEST_v7_5_TEST_APK**, חלץ אותו והתקן את `app-debug.apk`.

**שימו לב:** קובץ הפרויקט צריך לעלות פעם אחת למאגר. עד אז אין APK חדש לגרסה 7.5, וההרצות הישנות הן של 7.4 או גרסאות קודמות.

### שינויי כלכלה

כל משחק הוא סט של 8 שאלות, וניצחון מזכה דורש לפחות 6 נכונות (חוץ ממצבי תרגול עצמי/אבחון).
- בארבעת הניצחונות הראשונים ביום **בכל עולם נבחר**: 220 גביעים ו־50 קרדיטים.
- מהניצחון החמישי ואילך באותו עולם: 110 גביעים ו־25 קרדיטים.
- במצב ״כל העולמות״: בשני הניצחונות הראשונים 110 גביעים ו־25 קרדיטים; אחריהם 55 גביעים ו־12 קרדיטים.
- לימוד אות חדשה פעם אחת: 90 גביעים ו־20 קרדיטים.
- גביעים **אינם נצרכים** ברכישות; הם פותחים דרגות תהילה וספי דמויות וסקינים.
- הקרדיטים **משמשים לרכישה** של דמויות וסקינים לאחר השלמת המשימות.
- גביעי תהילה: 24 רמות עד גלקסיה III ב־60,000 גביעים.
- בכל כרטיס דמות/סקין מוצגים סף הגביעים, מחיר הקרדיטים ומשימות התרגול.
- הדמות הראשונה בכל עולם חינמית. שלוש האחרות נרכשות בקרדיטים לאחר השלמת המשימות וסף הגביעים.

**תכנון לפי 25 משחקים מוצלחים ליום** בעולם אחד: 3,190 גביעים ו־725 קרדיטים ביום, בתוספת תגמולי אותיות שנלמדות לראשונה. סיום ארבעת העולמות מיועד לכעשרה ימי תרגול; דרגת התהילה האחרונה מיועדת למשחק ממושך יותר.

### שדרוג והתקדמות קיימת

גרסה 7.5 משתמשת באותו מזהה אפליקציה `com.abcquest.kids.preview` ובאותו מפתח חתימת TEST של גרסה 7.4. התקן **מעל** `ABC QUEST · TEST`, ללא הסרה, כדי לשמור את נתוני המשחק.

בעת השדרוג הראשונה בלבד, הגביעים הישנים מוכפלים ב־30 והקרדיטים הישנים מוכפלים ב־4, בהתאם לסולם החדש. דמויות וסקינים שכבר נפתחו נשמרים. ההמרה מוגבלת לפעם אחת לפי `economyVersion`.

### גרפיקה וקול

לוגו ההרפתקה משולב במסך הבית ובאייקון Android. קובצי 64 הסקינים בפורמט JPEG כלולים בארכיון.

**השמע המתכתי טרם הוחלף.** ההקלטות האנושיות ופתרון הקריינות נדחו לגרסה עתידית לבקשת המשתמש.

### אבטחה

המפתח `abcquest-test.keystore` שבחבילת הניסוי מיועד רק לגרסאות Debug, ויכול להיות ציבורי. לפרסום רשמי בחנות נדרש מפתח חתימה פרטי אחר. המאגר כרגע ציבורי; אין להעלות אליו נתוני ילדים או מפתחות API.
