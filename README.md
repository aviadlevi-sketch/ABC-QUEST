# ABC QUEST — גרסת הרפתקה 7.3 (Android TEST)

משחק ללימוד אותיות באנגלית לילדים דוברי עברית, ובו ארבעה עולמות, 16 דמויות, חנות סקינים, משימות עולם ודרגות תהילה.

## הפקת APK לבדיקה בטלפון

**גרסה 7.3 מתקבלת מארכיון חדש, ולא מארכיון גרסה 7 הקיים במאגר.**

1. הורד מצ'אט ChatGPT את `ABC_QUEST_Android_v73_להעלאה_GitHub.zip`.
2. במאגר לחץ **Add file → Upload files** והעלה את ה־ZIP עצמו (בלי לחלץ).
3. לחץ **Commit changes** לענף **main**. GitHub Actions יתחיל אוטומטית להריץ את **Build ABC QUEST Android APK**.
4. לאחר שההרצה ירוקה, פתח אותה, וב־**Artifacts** הורד `ABC_QUEST_v7_3_TEST_APK`.
5. חלץ את הקובץ `app-debug.apk` והתקן בטלפון Android.

[רשימת ההרצות והורדת APK](../../actions/workflows/build-android-apk.yml)

## למה מתקינים לצד הגרסה הקודמת?

חבילת הניסוי החדשה משתמשת במזהה האפליקציה `com.abcquest.kids.preview`, ולכן היא תותקן **לצד** גרסה 7.2 ולא תדרוש להסיר אותה. ההתקדמות בגרסה הישנה נשמרת בנפרד; גרסת הניסוי החדשה מתחילה מהתחלה כדי לבדוק את קצב התקדמות ההרפתקה. הדמויות הישנות עדיין מופיעות בגרסה הישנה.

ה־APK החדש נחתם במפתח בדיקות קבוע (הכלול בארכיון), כדי שיהיה אפשר לעדכן את גרסת **TEST** בהמשך מבלי לאבד התקדמות של **TEST** בכל בנייה. מפתח בדיקות זה גלוי ואינו מתאים כלל לפרסום אפליקציה בחנות.

## המכניקה החדשה

- **4 עולמות:** יער האותיות (A–F), עמק הצלילים (G–L), אי האוצרות (M–R), טירת האלפבית (S–Z).
- **16 דמויות, 4 בכל עולם.** הגיבורה החדשה: **אסטרה**, עם 4 סקינים מובחנים.
- **דמות ראשונה:** עם פתיחת העולם.
- **דמות שנייה:** 2 אותיות + 2 משחקים מוצלחים (6/8 תשובות נכונות לפחות).
- **דמות שלישית:** לפחות 65% מאותיות העולם + 4 משחקים מוצלחים + יומיים שונים + 2 סוגי משחק + פתיחת הדמות הקודמת.
- **דמות רביעית:** כל אותיות העולם + 7 משחקים מוצלחים + יומיים שונים + 3 סוגי משחק + פתיחת הדמות הקודמת.
- **עולם חדש** נפתח רק לאחר פתיחת הדמות הרביעית בעולם הקודם. לכן נדרשים **לפחות חמישה תאריכי תרגול שונים** כדי לסיים את כל ארבעת העולמות, גם כשמשחקים מהר מאוד.
- **חדר משחקים:** בחירה של עולם מסוים או כל העולמות. רק ניצחונות במצב העולם המסוים מקדמים את משימות אותו עולם.
- **פרסים:** עד ארבעה ניצחונות מזכים בעולם וביום; 8 גביעים ו־12 קרדיטים לניצחון. חזרה על אות שכבר נלמדה אינה מעניקה פרס נוסף.
- **דרגות תהילה:** התקדמות לפי הישגים וימי תרגול. גרסאות קיימות שומרות הישגים כאשר מתעדכנים בתוך אותו מזהה אפליקציה; אפליקציית TEST נפרדת.

## פרטיות ושמע

המשחק עובד ללא שרת ושומר נתונים מקומית. קובצי שמע מוקלטים יכולים להיות מוטמעים תחת `app/src/main/assets/audio` עם רישיון שימוש והפצה. ה־ZIP אינו מכיל הקלטות אנושיות חדשות; הקריינות הקיימת עדיין זמינה.

אל תעלו למאגר הציבורי נתוני ילדים, סיסמאות, הקלטות משתמשים או מפתחות חתימה פרטיים.
